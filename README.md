# Bond Releases

Public download repository for **Bond**, a local-first AI team coordination
desktop app by LaGuardAI.

> **Status: scaffolding only.** Installers and documentation are being prepared
> and will be published in this repository as alpha releases roll out.

## What's in this repository

| Path | Contents |
|---|---|
| [`docs/`](./docs) | Installation and usage guides (in preparation) |
| [`starter-workspaces/`](./starter-workspaces) | Sample workspace templates you can import to get started (in preparation) |
| [`CHANGELOG.md`](./CHANGELOG.md) | Per-release notes |
| [Releases tab](https://github.com/LaGuardAI/bond-releases/releases) | The actual installers (`.exe` for Windows, `.dmg` for macOS) |

## Versioning

Releases follow [Semantic Versioning](https://semver.org/) with `-alpha.N`
pre-release identifiers during the alpha phase, e.g. `v1.4.5-alpha.1`. Once
Bond reaches general availability, the `-alpha.N` suffix is dropped.
