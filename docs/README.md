# Lorah documentation

These guides cover the standalone desktop application. Start with one
project and one useful question; there is no need to learn every surface
before doing real work.

| Guide | Purpose |
|---|---|
| [Install on Windows](install-windows.md) | Download and install the Windows application. |
| [Install on macOS](install-macos.md) | Choose the Apple silicon or Intel installer. |
| [First run](first-run.md) | Set up a project, connect model access and do a first task. |
| [Working with Lorah](alpha-user-guide.md) | Specialists, documents, reviewed Memory and model usage. |
| [Starter workspaces](../starter-workspaces/README.md) | Explore an example before adapting the structure to your work. |

The [website Quickstart](https://lorah.ai/quickstart/) contains the detailed
walkthrough. Check the [release notes](https://github.com/LaGuardAI/bond-releases/releases)
for your installed version when following a newly introduced feature.

The `alpha-user-guide.md` filename is retained so existing links continue to
work. It is not an invitation or licensing requirement.

See the [repository README](../README.md) for downloads and a data-flow
summary. For help, email [support@lorah.ai](mailto:support@lorah.ai). Report
vulnerabilities through [SECURITY.md](../SECURITY.md), without posting
sensitive details publicly.
