# Bond documentation

This directory will hold the alpha user-facing guides:

| File | Purpose |
|---|---|
| `install-windows.md` | Windows installation walkthrough, including SmartScreen warning guidance until Authenticode signing lands |
| `install-macos.md` | macOS installation walkthrough, including Gatekeeper / notarization guidance until Apple notarization lands |
| `first-run.md` | What to expect on first launch — workspace creation, provider keys, redemption code entry |
| `alpha-user-guide.md` | How to use Bond as an alpha user — workflows, capabilities, known limitations |

_These documents are being prepared and will be added as alpha releases approach._
